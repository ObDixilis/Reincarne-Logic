# Reincarne Logic

A lightweight static site that documents the Reincarne Logic practice. The
navigation highlights a small set of top-level destinations, groups related
content within dropdown menus, and keeps anchors available for deep pages.

## Getting started

Open `index.html` in a modern browser to explore the site. All assets are local,
so no build step is required.

## Structure

- `index.html` – landing page with anchor navigation and summaries of key work.
- `pages/overview.html` – outlines our core principles and engagement model.
- `pages/research.html` – collects field notes and in-progress experiments.
- `pages/faq.html` – answers common questions about the practice.
- `assets/css/styles.css` – shared styling, including the fixed header and
  dropdown menus.
- `assets/js/navigation.js` – manages responsive navigation and dropdown
  behavior.
